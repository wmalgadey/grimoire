# Kubernetes

Kubernetes schedules containerized workloads across a cluster of machines, handling
placement, restart-on-failure, service discovery, and rolling updates. Workloads are
described declaratively as resources (Deployments, Services, ConfigMaps, …) and a set
of controllers continuously reconciles the cluster's actual state toward the desired
state described in those resources.
